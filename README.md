# Snake Game 🐍

This is a simple Python-based Snake Game! The goal is to control the snake to eat food, grow longer, and avoid hitting the walls.

## Features:
- Classic Snake Game mechanics.
- Use arrow keys to control the snake's movement.
- Avoid collisions with the walls or the snake's own body.

## How to Play:
1. Run the `snakegame.py` file or the `.ipynb` file.
2. Use the arrow keys to guide the snake to the food.
3. Grow the snake by eating food and avoid hitting walls.

## Requirements:
- Python 3.x
- Pygame (for `.py` version)
- Jupyter Notebook (for `.ipynb` version)
